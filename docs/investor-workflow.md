# 투자자 워크플로

`/investor`는 종목 후보를 발견하고 현재 확인 가능한 사실을 바탕으로 개인 연구 기록(thesis)을 남기는 화면입니다. 한국·미국 시장의 후보는 KIS 순위 첫 페이지에 한정되며 전체 시장이나 저평가 종목을 보장하지 않습니다. 코드를 직접 입력해 허용된 시장의 상세 조회를 요청할 수도 있습니다.

상세 화면은 현재가·PER·PBR·EPS·성장·ROE·부채와 자료의 source, 조회 시각, 누락 이유를 따로 표시합니다. 조회 완료 시각은 거래소 시세 시각이나 재무 기간 종료·공시 시각이 아닙니다. 현재 자료만 사용하므로 과거 시점에 해당 자료를 알 수 있었다고 해석하지 않습니다.

가치 진입은 사용자가 정규화 EPS, EPS 기간, 목표 PER 하한·상한, 안전마진, 근거를 입력할 때만 검토합니다. 계산 범위는 `EPS × 목표 PER`이며 자동 내재가치가 아닙니다. 안전마진 가격은 하한에 `(1 - 안전마진)`을 곱한 값입니다. ETF와 타입 미확인 종목에는 기업 EPS 가치평가를 적용하지 않습니다.

초기 추세 진입은 조정 여부가 확인된 완료 일봉에서 최신 종가가 직전 20일 고점과 직전 20일 평균 거래량을 동시에 넘고 전일에는 같은 돌파가 아니었는지를 관찰합니다. 보유 thesis의 훼손은 완료 종가가 각 날짜의 SMA20 아래에 이틀 연속인지로 관찰합니다. 일봉 누락·중복·미래 시각·조정 불명확이면 판단을 보류합니다. 이 규칙은 돌파 관찰이며 상승 시작이나 검증된 전략을 뜻하지 않습니다.

thesis에는 관찰·보유·종료 상태, 가치·추세 진입 이유, 근거, 무효화 조건, 다음 검토일, 사용자가 표시한 유지·훼손·미확인 상태, 선택 위험 가격과 가치 가정을 저장합니다. 저장 시 최신 분석 snapshot과 revision history를 남기며, 이는 사용자의 연구 기록이지 증권사 체결·보유 상태가 아닙니다. revision이 맞지 않는 동시 수정은 거절합니다. 현재 가격이 없거나 오래되었다고 자동 매수·매도 권고를 만들지 않으며, 검토일 초과는 별도 상태입니다.

fixture 앱은 합성 데이터임을 표시하고 주식·ETF·타입 미확인·누락 사례를 제공합니다. 합성 사례는 실제 계좌, 시세, 성과를 의미하지 않습니다. 이 기능은 알림이나 자동 주문을 보내지 않으며 실거래 검증에 사용하지 않습니다.
