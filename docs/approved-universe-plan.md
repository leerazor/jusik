# 사용자 등록 종목 연구 계획

## 목적과 현재 범위

사용자가 직접 고른 한국·미국 종목의 단순 보유보다 비용 차감 수익과 위험이 나은지 빠르게 확인한다. 초기 목록은 비어 있다. 등록은 종목 코드와 거래소의 저장이며 가격 적격성이나 매수 승인으로 해석하지 않는다. 현재 단계는 수동 개발과 등록 UI/API만 포함한다. 기존 자동 연구 runner는 신규 dispatch를 중단한다. 기존 R0–R7 결과는 보존하되 이 경로의 선행 차단 조건으로 두지 않는다.

## 순서와 인수 조건

1. **목록 등록:** 한국 KRX 6자리 영숫자 코드 또는 미국 티커와 NAS·NYS·AMS 거래소를 사용자가 명시한다. 별도 SQLite에 원자적으로 저장하고 revision과 시각을 돌려준다. 기존 운영 universe·PAPER·stream에 연결하지 않는다.
2. **자료 검증:** 등록 시점 이후 사용할 가격, 배당, 분할, 환율, 거래 달력과 비용 가정을 종목별로 확인한다. 실제 조회 범위·누락·관측 가능 시점·출처가 부족하면 해당 종목의 비교를 차단한다. 등록 완료를 자료 통과로 표시하지 않는다.
3. **같은 목록의 기준선과 후보:** 단순 보유 기준선과 최대 3개의 사전등록된 낮은 회전율 매수·보유·매도·현금 후보를 동일 기간·통화·종목·비용으로 비교한다. 수수료·세금·스프레드와 FX 비용을 포함하고 거래 수·회전율을 표시한다. 후보 규칙과 비용, 자료, 평가 기간은 결과 전에 고정한다.
4. **미래 구간 검증:** bounded IS, 별도 validation과 시간 순 walk-forward 뒤 미사용 OOS를 단회 판정한다. OOS를 보고 후보를 재조정하지 않는다. 비용 차감 CAGR·MDD·Sharpe·Calmar를 함께 보고 MDD 20% hard filter 및 required return과 자료 게이트를 적용한다. 자동 winner나 승격은 없다.
5. **PAPER와 live:** 독립 위험·자료 검토를 통과한 후보만 격리 PAPER 검토로 보낸다. 현재 PAPER 10% 대응 계약은 그대로 유지한다. 실제 주문은 별도 명시 승인·설정·안전 검토 전까지 연결하지 않는다.

초기 자본 1억원, 중간 인출 없음, 레버리지 상품 배분 상한 20%, 최대 낙폭 20% hard filter를 유지한다. 미래 수익이나 완료 시점을 약속하지 않는다. 자료가 준비되지 않은 종목은 결손을 메우거나 과거 상장을 가정하지 않고 부족한 근거를 기록한다.
