# 일반 투자자용 웹 설계 기준

## 목적

처음 방문한 사람이 이 프로젝트가 무엇을 검증하는지, 현재 결과를 얼마나 믿을 수 있는지, 계속 연구할 근거가 있는지 판단할 수 있도록 한다. 기능 수나 개발 완료 건수를 투자 준비도로 표현하지 않는다. 좋은 과거 결과가 실거래 적합성이나 미래 수익의 증명이라는 인상을 주지 않는다.

## 방문자가 따라갈 이야기

1. **투자 목표:** 1억원을 여러 종목에 나누고 불필요한 현금과 잦은 거래를 줄이는 방법을 연구한다. 운용 중 최고 평가액 대비 20% 하락은 목표 한도이며 보장된 손실 제한이 아니다.
2. **현재 위치:** 과거 자료 비교와 모의 관찰은 다른 증거다. 새로운 연구 후보를 모의 운용이나 실거래에 자동으로 반영하지 않는다. 자동 개발 상태와 투자 전략 검증 단계를 구분한다.
3. **확인한 결과:** 같은 종목·기간·비용 조건의 기존 방식과 변경안을 비교한다. 누적 수익률, 중간에 겪은 최대 하락, 투자하지 않은 현금, 거래한 날과 비용의 의미를 함께 설명한다. 대표 비교는 최고 성과나 최종 채택안이 아니다.
4. **아직 모르는 점:** 현금 감소와 함께 위험·비용이 증가할 수 있다. 과거 자료 재사용, 배당·세금 누락, 자료 시점의 불완전성, 비교용 단순 투자안과의 검증 부족을 숨기지 않는다. 확인되지 않은 자료는 성공이나 0으로 표현하지 않는다.
5. **다음 판단:** 위험과 비용을 함께 감안한 개선이 독립 검증에서도 유지되는지 확인한다. 이를 충족하지 못하면 후보를 보류하고 접근을 바꾼다. 이 화면은 프로젝트 지속을 설득하는 홍보물이 아니라 그 여부를 판단하는 자료다.

## 정보 구조

- 연구 홈은 설명과 판단을 위한 시작점이다. 첫 방문자에게 연구 실행 폼이나 운영 설정을 먼저 요구하지 않는다.
- 성과 비교, 모의 관찰, 개발 기록, 연구 도구의 역할과 이동 경로를 일관되게 표시한다. 메뉴는 읽기 순서를 안내하며 반드시 실행해야 하는 절차로 오해시키지 않는다.
- 상세 표·원본 보고서·연구 실행·기존 계좌 조회 기능은 접근 가능한 별도 영역에 보존한다. 계좌 URL과 인증 경계는 변경하지 않는다.
- 전문 용어는 처음 등장하는 곳에서 쉬운 말로 풀어 쓴다. 데이터의 실제 범위·단위·기준일과 알려지지 않은 상태를 유지한다.

## 검증 기준

- 첫 화면과 주요 링크만 읽고 방문자가 목표, 현재 단계, 수익률의 기간, 위험의 의미, 다음 확인 사항을 설명할 수 있어야 한다.
- 구현과 독립된 검토자가 투자 경험이 적은 방문자의 과제로 경로를 점검한다. 실제 일반 투자자 사용자 시험을 하지 않았다면 수행했다고 주장하지 않는다.
- 실제 데스크톱과 모바일 브라우저에서 읽기 순서, 제목 구조, 키보드 이동, 가로 넘침, 링크, 빈 데이터·실패 상태를 확인한다.
- 기존 기능의 연결과 서버 액션 경로를 보존하고 lint, 타입 검사, 프로덕션 빌드를 통과한다. 운영 변경 액션과 실제 주문은 검증 목적으로 실행하지 않는다.

## 이번 작업의 운영 조건

사용자 요청에 따라 자동 개발을 중지한 상태에서 웹을 개선한다. 웹 개선을 마쳐도 자동 개발을 재개하지 않는다. 전략 연구, 거래 정책 변경, 인증 변경, 새 성과 실험은 이번 작업 범위에 포함하지 않는다.

## 현재 화면 구성 (2026-09-26)

주 메뉴는 `한눈에 보기`(`/research`), `연구 결과`(`/research/progress`), `모의 관찰`(`/research/forward`) 세 가지입니다. `더 보기`를 펼치면 종목 직접 연구, 연구 기록, 연구 도구, 시장자료 연구, 계좌 현황으로 이동할 수 있습니다. 시장자료 하위 화면과 연구 도구가 동시에 현재 메뉴로 표시되지 않도록 경로를 구분합니다.

### 한눈에 보기

- 첫 화면에는 공개된 과거 연구의 대표 비교에서 확인한 결론과 신뢰 범위를 놓습니다. 자료 공개 시각과 화면 확인 시각은 별도로 표시하며, 현재 진행 중인 전체 연구의 최신 결론이라고 주장하지 않습니다.
- 대표 비교는 API에 지정된 항목만 사용합니다. 지정되지 않았으면 다른 결과를 임의로 고르지 않습니다. 알려진 연구의 식별 정보가 맞을 때만 연구 설명과 쉬운 결론을 붙입니다.
- 기존 방식과 시험한 방식의 기간 누적 수익률, 최대 하락 폭, 현금 비중, 비용, 거래한 날, 연환산 회전율을 나란히 보여줍니다. 쉬운 질문과 원래 지표 이름을 함께 표시합니다. 기간·비용 배수·현금 통계·낙폭 기준을 수치 옆에 유지합니다.
- 공개된 비교에서 현금 감소·수익 증가·낙폭 증가·비용 증가가 함께 나타난 경우 그 상충을 먼저 설명합니다. 여러 규칙을 함께 바꾼 결과를 한 규칙의 인과 효과로 표현하지 않습니다.
- 다음 확인 질문은 결론 카드 바로 뒤, 수치 비교보다 앞에 배치하고 보고서의 한계에 연결합니다. 긴 연구별 한계는 같은 위치에서 펼쳐 볼 수 있습니다. 후속 작업이 실제 실행 중이라고 표현하지 않습니다. 전체 연구 목록은 연구 결과로 옮기고, 목표와 운용 조건은 펼쳐서 확인합니다.

### 연구 결과

대표 비교를 연구 목록보다 먼저 표시합니다. 각 연구는 질문, 식별 정보가 확인된 결론, 주요 한계를 먼저 보여줍니다. 원본 보고서와 `study-*` 링크 대상은 접힌 영역 밖에 있습니다. 변경 규칙·추가 한계·모든 비교 표는 기본적으로 접으며, 수치와 비용 조건은 그대로 확인할 수 있습니다. 자동 개발 실행기와 작업 목록은 별도 운영 상세에 보존합니다. 브라우저 기본 펼침 요소를 사용해 키보드 접근을 지원합니다.

### 모의 관찰과 종목 직접 연구

모의 관찰은 새 시세로 별도 가상 계좌의 기록을 쌓는 기능입니다. PAPER 10% 종가 방어 기준과 현재 연구의 20% 목표를 구분합니다. 실제 운용 상태와 기록 시각을 표시하며, 가상 체결의 완료 기록을 연구 검증 완료로 표현하지 않습니다. 검증 대상 불일치·API 실패·입력 차단·거래일 달력 차단·기업행동 차단은 상세를 펼치기 전에도 표시합니다. 시계·시세 연결·달력·기업행동·가상 원장과 파일 다운로드는 펼쳐서 확인합니다.

`/investor`는 관심 종목을 직접 찾아보고 투자 메모를 작성하는 선택 도구입니다. 연구 결과를 읽기 위한 필수 단계가 아닙니다. 원래 조회와 기록 기능을 유지하며 연구 첫 화면으로 돌아갈 수 있습니다. 오타 경로 `/invester`는 `/investor`로 이동합니다.

### 확인 범위와 실행 경계

정상 자료, 공개 연구 없음, 자료 미제공, 검증 실패, API 오류, 대표 비교 미지정, 연구 설명 식별 불일치를 서로 구분합니다. 검증된 수치가 있어도 식별 정보가 맞지 않는 설명은 표시하지 않습니다. 모의 관찰의 상태·원장·검증 등록 중 일부만 확인되는 경우 전체 정상으로 표시하지 않습니다.

이번 변경은 프런트엔드와 이 문서에 한정합니다. 기존 3000 포트의 서비스를 종료하면 `start.sh`의 종료 처리가 백엔드에도 영향을 주므로 기존 서비스를 재시작하지 않습니다. 별도 로컬 미리보기와 기존 서비스의 배포 상태를 구분해서 안내합니다. 실제 사용자 시험과 로컬 fixture 기반 브라우저 검증은 서로 다른 검증입니다.
