# 일반 투자자용 웹 설계 기준

## 목적

처음 방문한 사람이 이 프로젝트가 무엇을 검증하는지, 현재 결과를 얼마나 믿을 수 있는지, 계속 연구할 근거가 있는지 판단할 수 있도록 한다. 기능 수나 개발 완료 건수를 투자 준비도로 표현하지 않는다. 좋은 과거 결과가 실거래 적합성이나 미래 수익의 증명이라는 인상을 주지 않는다.

## 방문자가 따라갈 이야기

1. **투자 목표:** 1억원을 여러 종목에 나누고 불필요한 현금과 잦은 거래를 줄이는 방법을 연구한다. 운용 중 최고 평가액 대비 20% 하락은 목표 한도이며 보장된 손실 제한이 아니다.
2. **현재 위치:** 과거 자료 비교와 모의 관찰은 다른 증거다. 새로운 연구 후보를 모의 운용이나 실거래에 자동으로 반영하지 않는다. 자동 개발 상태와 투자 전략 검증 단계를 구분한다.
3. **확인한 결과:** 연구자가 만든 두 가상 설정을 같은 종목·기간·비용 조건으로 비교한다. 누적 수익률, 중간에 겪은 최대 하락, 투자하지 않은 현금, 거래한 날과 비용의 의미를 함께 설명한다. 대표 비교는 최고 성과나 최종 채택안이 아니다.
4. **아직 모르는 점:** 현금 감소와 함께 위험·비용이 증가할 수 있다. 과거 자료 재사용, 배당·세금 누락, 자료 시점의 불완전성, 비교용 단순 투자안과의 검증 부족을 숨기지 않는다. 확인되지 않은 자료는 성공이나 0으로 표현하지 않는다.
5. **다음 판단:** 위험과 비용을 함께 감안한 개선이 독립 검증에서도 유지되는지 확인한다. 이를 충족하지 못하면 후보를 보류하고 접근을 바꾼다. 이 화면은 프로젝트 지속을 설득하는 홍보물이 아니라 그 여부를 판단하는 자료다.

## 정보 구조

- 연구 홈은 설명과 판단을 위한 시작점이다. 첫 방문자에게 연구 실행 폼이나 운영 설정을 먼저 요구하지 않는다.
- 성과 비교, 모의 관찰, 개발 기록, 연구 도구의 역할과 이동 경로를 일관되게 표시한다. 메뉴는 읽기 순서를 안내하며 반드시 실행해야 하는 절차로 오해시키지 않는다.
- 상세 표·원본 보고서·연구 실행·기존 계좌 조회 기능은 접근 가능한 별도 영역에 보존한다. 계좌 URL과 인증 경계는 변경하지 않는다.
- 전문 용어는 처음 등장하는 곳에서 쉬운 말로 풀어 쓴다. 데이터의 실제 범위·단위·기준일과 알려지지 않은 상태를 유지한다.

## 검증 기준

- 첫 화면과 주요 링크만 읽고 방문자가 목표, 현재 단계, 수익률의 기간, 위험의 의미, 다음 확인 사항을 설명할 수 있어야 한다.
- 구현과 독립된 검토자가 투자 경험이 적은 방문자의 과제로 경로를 점검한다. 실제 일반 투자자 사용자 시험을 하지 않았다면 수행했다고 주장하지 않는다.
- 실제 데스크톱과 모바일 브라우저에서 읽기 순서, 제목 구조, 키보드 이동, 가로 넘침, 링크, 빈 데이터·실패 상태를 확인한다.
- 기존 기능의 연결과 서버 액션 경로를 보존하고 lint, 타입 검사, 프로덕션 빌드를 통과한다. 운영 변경 액션과 실제 주문은 검증 목적으로 실행하지 않는다.

## 이번 작업의 운영 조건

초기 화면 개선은 당시 사용자의 자동 개발 중지 요청에 따라 수행했다. 이는 과거 작업의 조건이며 현재 실행기 상태나 이후 재개 승인을 대신하지 않는다. 서비스 중지·재개와 배포는 현재 사용자의 명시적 요청과 운영 기록을 기준으로 별도 관리한다. 보고서 웹 읽기 구현은 실행기를 조작하지 않으며 전략, 거래 정책, 인증, 성과 실험을 변경하지 않는다.

## 현재 화면 구성 (2026-09-26)

주 메뉴는 `한눈에 보기`(`/research`), `연구 결과`(`/research/progress`), `모의 관찰`(`/research/forward`) 세 가지입니다. `더 보기`를 펼치면 종목 직접 연구, 연구 기록, 연구 도구, 시장자료 연구, 계좌 현황으로 이동할 수 있습니다. 시장자료 하위 화면과 연구 도구가 동시에 현재 메뉴로 표시되지 않도록 경로를 구분합니다.

### 한눈에 보기

먼저 과거 주가에 연구자가 만든 규칙을 적용해 가상의 돈으로 사고팔았다고 계산하는 연구임을 설명합니다. 사용자가 설정을 입력하거나 투자 방식을 선택하는 절차가 아닙니다. 읽는 순서는 짧은 비교 결론, 두 시험의 차이 표, 얻은 것과 감수한 것의 비교 그래프, 프로그램의 점검 행동, 아직 확인할 것입니다.

대표 비교는 API에 지정된 항목만 사용합니다. 질문 바로 아래에 현재 비교의 수익·하락·비용·현금 변화 결론을 짧게 표시합니다. 조건은 의미별 행과 두 시험 열이 있는 표로 대응합니다. 기간 전체 수익, 최고점에서 떨어진 최대 폭, 거래·환전 비용 합계, 현금 비율 네 항목은 기본 화면에서 각각 두 가로막대로 비교합니다. 회전율·거래한 날 수와 계산 예시는 펼쳐 읽습니다. 원래 값과 기간·비용 조건·현금 통계·낙폭 기준을 보존합니다. 프로그램의 점검은 결과 뒤의 세 단계 도식으로 보여주며, 가상 금액 예시는 실제 연구 성과와 구분합니다.

마지막에는 좋아진 점과 감수한 점을 각각 말할 수 있으면 요약을 이해한 것임을 안내합니다. 더 읽고 싶은 사람은 다른 기간의 결과로 이동합니다. 배당·세금 누락과 과거 판단에 당시 알 수 없던 정보가 섞이지 않았는지 아직 검증하지 못한 한계를 설명합니다. 자료 공개 시각과 화면 확인 시각은 별도로 표시합니다.

### 연구 결과

대표 비교와 개별 연구를 목적·행동·결과 순서로 읽습니다. 연구 목록은 쉬운 질문과 결론, 읽을 때 확인할 점을 보여주고, 모든 비교 표와 전문적인 설정은 펼쳐 읽습니다. 보고서와 연구별 링크 대상은 접힌 영역 밖에 유지합니다. 자동 개발과 작업 목록은 별도 운영 상세에 보존합니다.

### 모의 관찰과 종목 직접 연구

모의 관찰은 새 가격을 받은 프로그램이 판단과 가상 매매를 기록하는 별도 계좌입니다. 앞선 연구 방식이 자동 적용되지 않습니다. 현재 상태가 뜻하는 행동과 최근 기록 시각을 설명하며, 다음 계산 예정일을 독자의 거래일로 해석하지 않게 합니다. 검증 계획과 계좌의 불일치, 계획 형식 실패, 자료 응답 실패를 확인 가능한 범위에서 구분합니다. 운영자 확인이 필요한 항목과 독자가 지금 읽을 수 있는 자료를 안내하며, 제공되지 않은 복구 시각은 만들지 않습니다. PAPER 10% 종가 방어와 연구의 20% 목표는 별도 기준으로 유지합니다.

`/investor`는 관심 종목을 직접 찾아보고 투자 메모를 작성하는 선택 도구입니다. 연구 결과를 읽기 위한 필수 단계가 아닙니다. 상세 입력은 메모 예시와 선택 가격 가정의 의미를 설명합니다. EPS·PER 등 선택 값을 모르면 추측해 입력하지 않고 비워 둘 수 있습니다. 원래 조회·기록·서버 액션은 유지하며, 오타 경로 `/invester`는 `/investor`로 이동합니다.

### 확인 범위와 실행 경계

정상 자료, 공개 연구 없음, 자료 미제공, 검증 실패, API 오류, 대표 비교 미지정, 연구 설명 식별 불일치를 서로 구분합니다. 검증된 수치가 있어도 식별 정보가 맞지 않는 설명은 표시하지 않습니다. 모의 관찰의 상태·원장·검증 등록 중 일부만 확인되는 경우 전체 정상으로 표시하지 않습니다.

보고서 웹 읽기 변경은 프런트엔드와 이 문서에 한정합니다. 초기 화면 개선은 별도 로컬 미리보기로 검증했으며, 이후 배포 여부는 현재 운영 기록을 확인합니다. `start.sh` 아래 프런트엔드를 종료하면 함께 실행된 백엔드에도 영향을 줄 수 있으므로 배포 담당자가 현재 프로세스 구성을 확인하고 승인된 범위에서 적용합니다. 구현 담당자는 서비스나 실행기를 직접 조작하지 않습니다. 실제 사용자 시험과 로컬 fixture 기반 브라우저 검증은 서로 다른 검증입니다.


## 보고서는 웹에서 읽기

보고서 동작은 다운로드 대신 `/research/reports/`의 웹 읽기 화면으로 연결합니다. 연구 이력은 `history/<artifact SHA-256>`, 포트폴리오와 배당 연구는 각각 `portfolio/<run ID>`, `dividends/<run ID>`, 참고 자료는 `reference/<허용된 이름.md>`를 사용합니다. 기존 Markdown 다운로드 주소는 새 주소로 307 이동하며 CSV·JSON 내보내기는 유지합니다. 이전 브라우저가 이미 영구 캐시한 이력 다운로드 응답은 서버에서 회수할 수 없으므로 화면 링크는 새 주소를 직접 사용합니다.

본문 전체를 제목, 목차, 표, 목록, 코드와 인용으로 표시합니다. 모바일에서는 표 자체를 가로로 이동할 수 있습니다. 원문의 수치·표현은 바꾸지 않습니다. HTML은 실행하지 않는 문자로 표시하고 외부 이미지는 자동으로 불러오지 않습니다. 링크는 등록된 보고서, 허용된 읽기 화면, 본문 위치와 HTTP(S) 참고 자료만 활성화합니다. 지원하지 않는 Markdown 주소와 위험한 주소는 설명 문구만 남깁니다. 자료 없음·빈 본문·연결 실패·내용 해시 불일치는 서로 다른 안내와 웹 재시도 경로로 표시하며 파일 다운로드로 우회하지 않습니다.

## 비교 설정과 검토 간격 설명

`연구용 비교 설정`과 `변경해서 시험한 설정`은 둘 다 과거 자료로 계산한 연구용 가정입니다. 사용자의 이전 투자 방식이나 실제 보유 내역을 의미하지 않습니다. 연구 식별 정보가 확인되지 않으면 특정 규칙 설명을 붙이지 않습니다.

확인된 대표 비교에는 투자 상한 60%와 95%, 연 변동성 목표 10%와 30%, 4주와 8주의 보유 비중 검토 간격, 해당 후보 A/B에 실제로 연결된 비중 밴드를 수치보다 앞에 보여줍니다. 주기뿐 아니라 여러 설정을 함께 바꾼 결과이므로 주기 하나의 효과로 설명하지 않습니다.

4주·8주는 각각 28일·56일의 달력 간격으로 종목별 투자 비중을 다시 검토한다는 뜻입니다. 투자기간이나 매번 매매한다는 약속이 아닙니다. 실제 비중과 목표 비중의 차이가 밴드 안에 있는 등의 경우 거래를 건너뛰며, 위험 방어 매도는 정기 검토 사이에도 발생할 수 있습니다. 연 변동성 목표는 수익률의 흔들림을 조절하는 설정이며 약속된 수익률이나 최대 손실 한도가 아닙니다. 이러한 설명은 원문을 고치는 대신 비교 화면과 보고서 읽기 안내에 제공합니다.


## 화면만 보는 독립 이해도 검수

UI 완료에는 코드 검토와 별도로 구현 문맥 없는 agent의 실제 화면 검수를 포함합니다. 검수자는 코드·설계·API 자료를 받지 않고, PC와 모바일에서 화면과 일반적인 이동만 사용합니다. 페이지 목적, 비교의 출처와 이유, 프로그램의 행동과 간격, 결과의 의미와 한계, 독자의 다음 행동을 자기 말로 설명하고 화면 문구·주소를 근거로 남깁니다. 금융 지식으로 빈 설명을 추측해야 하면 실패입니다. 중요한 지적을 수정한 뒤 같은 화면에서 재검수합니다. 이는 초보 관점의 agent 검수이며 실제 초보 참여자 시험과는 구분합니다.

보고서 상단의 맞춤 설명은 기존 연구 ID·코드/결과/보고서 hash 검증을 모두 만족하는 자료에만 연결합니다. 설명 자료를 읽지 못해도 안전하게 확인된 원문은 계속 웹에서 읽습니다. 요약의 소수점 절삭과 보고서의 반올림 차이를 안내하고, 넓은 원문 표마다 좌우 이동 안내를 제공합니다.


## 글의 양과 시각적 비교

문장을 끝까지 읽으면 이해할 수 있다는 것만으로 요약 화면을 통과시키지 않습니다. 질문 근처에서 결론을 찾고, 설정 차이와 수익·위험·비용을 나란히 볼 수 있어야 합니다. 같은 설명의 반복을 줄이고 표와 짧은 행동 도식으로 바꿉니다. 모바일에서도 두 시험의 값은 같은 행에서 대응합니다.

각 결과 그래프의 두 막대는 같은 0선과 눈금을 사용합니다. 항목 사이에는 단위와 눈금이 다름을 표시합니다. 음수 수익은 0선 왼쪽, 0은 길이 없는 막대, 미확인 값은 막대 없이 표시합니다. 눈에 보이도록 작은 값을 임의로 늘리지 않습니다. 숫자와 변화 방향은 기존 Decimal 표시·비교를 사용하고 막대 길이만 근사합니다. 색은 두 시험을 구분하며 하락이나 비용 증가를 좋은 결과처럼 강조하지 않습니다. 집계값으로 실제 수익곡선을 만들어 내지 않습니다.
