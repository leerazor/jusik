## 변경과 결정

- `frontend/app/research/research-navigation.tsx`: 주 메뉴를 세 가지로 줄이고 기존 경로를 기본 HTML 펼침 메뉴에 보존했습니다. 알려진 경로를 먼저 판별해 시장자료와 연구 도구가 동시에 활성화되지 않게 했습니다.
- `frontend/app/research/page.tsx`: 대표 비교 하나의 결론, 신뢰 한계, 다음 확인 질문, 비교 수치 순서로 재구성했습니다. 대표 지정이 없으면 임의 선택하지 않습니다. 연구 식별 확인 후 Decimal 비교로 수익·현금·위험·비용의 동반 변화를 설명합니다. 전체 목표와 조건은 접힌 영역에 남겼습니다.
- `frontend/app/research/progress/page.tsx`: 대표 비교를 목록 앞에 배치했습니다. 각 연구의 질문·결론·주요 한계·보고서 링크를 유지하며 규칙과 전체 비교 표를 접었습니다. 운영 상세도 접힌 영역에 유지합니다.
- `frontend/app/research/forward/page.tsx`: 모의 계좌와 연구의 차이를 설명하고 실제 상태·기록 시각·검증 불일치를 앞에 표시합니다. 입력·달력·기업행동의 차단은 숨기지 않고, 기술 진단과 원장은 펼쳐서 확인합니다. 가상 체결 완료를 투자 검증 완료로 표현하지 않습니다.
- `frontend/app/investor/page.tsx`, `frontend/app/invester/page.tsx`: 종목 탐색과 투자 메모는 선택 도구임을 설명하고 연구 화면 복귀 및 오타 경로 이동을 제공합니다. 조회 폼과 저장 기능은 변경하지 않았습니다.
- 독립 검토에서 모바일의 다음 확인 질문이 수치 아래로 밀리는 점을 확인해 결론 카드 바로 아래로 옮겼습니다. 긴 연구별 한계는 같은 위치의 펼침 영역에 보존했습니다.
- 화면은 제한된 청록 강조색, 밝은 배경, 짧은 결론, 나란한 수치, 기본 HTML 펼침 요소를 사용합니다. 신규 의존성은 없습니다.
