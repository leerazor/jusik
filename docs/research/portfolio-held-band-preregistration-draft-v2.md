# 보유 밴드 후속 사전등록 초안 v2

> **상태: 실행 불가 초안(DRAFT).** 이 문서는 실험 등록이나 승인 문서가 아니다. `execution_allowed=false`이며, 실행·자료 수집을 허가하지 않는다.

## 목적과 알려진 결과

이 초안은 앞으로 새로 확보될 자료에서 보유 밴드 4%p 후보와 2%p 대조군을 비교할 준비 항목을 정리한다. 이는 과거 결과를 다시 시험하는 작업이 아니다. v1의 모든 결과는 이미 알려져 있으며, v1은 후향 자료를 사용했고 point-in-time(PIT) 적격성은 검증되지 않았다. v1 기간을 OOS로 부르거나, 그 결과를 새로운 독립 검증으로 제시해서는 안 된다.

확인된 고정 문맥은 다음과 같다.

- 현재 mandate JSON SHA-256: `22efba4714bc0baf65c56bdfd84dcdee91184a760a13d4d30c5a94486c264ab1`
- 준비 워크트리 기준 SHA: `10e092a55ab50d96b09fe8c15b2a535530a9f8ad`
- v1 원 실행 ID/SHA: `c94690f0ee13f01b1810ac0368e84fdcaeb1c1bbe7f396985d04dd3634b5ead0`
- v1 원자료와 결과의 마지막 날짜: `2026-09-08`
- 이전 v1 사전등록 SHA-256: `fa5065df2ae70d024656209b0a33b755071c1441ecfa3406db99973fda49277e`
- 이전 v1 manifest SHA-256: `bba3822f08a648462c8a2634c9402b545c833ad854bcb924fac96adb75d366a2`

2026-09-08 이후의 held-band 호환 신규 관측은 확인되지 않았다. v1 원본, archive, 결과, manifest와 과거 SHA 확인은 그대로 보존한다. v1 자료를 다시 만들거나 수정하지 않으며, 아래 제안의 승인 근거로 취급하지 않는다.

## 미래 비교의 가설적 범위

자료가 2026-09-08보다 뒤의 새 관측으로 확인되고 별도 등록을 통과하면, 4%p를 제안 후보, 2%p를 대조군으로 삼는 비교를 검토할 수 있다. 정확한 데이터 출처, universe, 등급, 기간과 자료 노출 상태가 정해지기 전에는 미래 비교의 적격성도 확정할 수 없다. 현재 확인되지 않은 표본, 비용, 제한, 결과 또는 가정은 채워 넣지 않는다. v1의 비용·한도와 기타 실행값을 신규 승인 파라미터처럼 복사하지 않는다.

과거에 이미 관측된 v1 구간은 미래 구간이 아니며, 이 비교의 OOS가 될 수 없다. 아직 손대지 않은 OOS 구간은 별도로 정의하고 단 한 번만 평가해야 한다.

## 적용할 연구 거버넌스

후속 등록이 별도 승인을 받을 경우 비용 차감 CAGR, MDD, Sharpe, Calmar를 각각 별도의 primary metric으로 보고한다. MDD `<= 20%`는 hard filter다. 후보는 최대 3개로 제한한다. 가중 합산 점수, 자동 승자 선정, 자동 승격, 같은 holdout을 이용한 재조정은 허용하지 않는다.

검증 순서는 제한된 IS, 별도 validation, 시간순 walk-forward, 한 번의 untouched OOS다. 실행 전에 각 후보의 요구수익률 지표·값·기간(horizon)을 고정해야 한다. 이 값이 미정이거나 기준에 미달하면 다음 단계로 진행하지 않는다. 예산도 실행 전에 확정해야 한다.

## 등록 전에 미정으로 남겨야 할 항목

다음 값은 현재 확인된 정보가 없으므로 미정이다. 임의 추정이나 v1 값의 복사로 채우지 않는다.

- 새 데이터 출처, universe, 데이터 등급, 대상 기간, 기존 결과에 대한 노출 여부
- IS·validation·walk-forward·OOS의 정확한 경계와 최소 표본 수
- 후보별 요구수익률의 지표, 값, horizon
- compute·data·artifact·evaluation 예산
- 최종 코드, 정책, 데이터 manifest hash

JSON에서는 각 미정 필드를 `null`로 유지했다. 등록 시 이 값들은 근거와 함께 결정되어야 한다.

## 차단 및 재개 조건

현재는 호환되는 새 관측이 확인되지 않았고 기간·최소 표본·요구수익률·예산이 미정이므로 등록과 실행을 차단한다. 새 관측이 v1 종료일보다 뒤에 존재하며 출처와 자료 노출 상태를 확인할 수 있어야 다시 검토할 수 있다. 현재 후보를 과거 universe에 소급해서는 안 된다. 그 뒤 등록 검토에서 모든 검증 기간과 최소 표본, 후보별 요구수익률 및 네 가지 예산을 고정하고, 최종 코드·정책·manifest hash를 확인한 다음 별도 명시 승인 여부를 판단한다. 조건이 모두 충족될 때까지 이 초안은 비실행 상태로 유지한다.

## 이번 준비 작업의 제외 범위

이번 변경은 문서 초안 두 개 작성으로 끝난다. 실험 실행, 자료 수집, 네트워크 호출, DB 접근·변경, PAPER 설정·상태 변경, runner 변경, 주문, v1 재실행 또는 재조정은 포함하지 않는다. 문서 검사는 JSON 파싱과 `git diff --check`로 제한한다.
