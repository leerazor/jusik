전략 연구, 이 순서로 시작하세요.

백테스트 한 번부터 저장·비교·반복 검증과 앱 모의 운용까지, 실제 화면 순서대로 설명합니다.

처음 5분정기 반복결과 읽기앱 모의 운용자주 묻는 문제

처음 5분

  1. 과거 데이터로 검증하기에서 6자리 국내 종목 코드와 날짜를 입력합니다. 예: 삼성전자(005930), SK하이닉스(000660)의 입력값은 005930, 000660입니다. 종목명 검색 입력은 지원하지 않습니다.
  2. 필요하면 자금·비용 및 고급 조건을 열어 가정을 바꾸고 백테스트 실행을 누릅니다.
  3. 검증 결과 확인하기의 검증 결과 목록에서 완료된 항목을 엽니다.
  4. 수익률, 최대 낙폭, 비용과 거래 수를 비교합니다. 여기까지가 기본 사용 흐름입니다.
  5. 원할 때만 정기 반복이나 앱 모의 운용을 설정합니다.

연구 대상은 실제 보유 종목일 필요가 없습니다.

백테스트는 과거 검증 한 번입니다. 전략 연구는 같은 엔진의 결과를 저장·비교하고 반복 검증해 앱 모의 운용까지 이어가는 과정입니다.

저장한 종목을 정기적으로 검증하기

수동 연구과거 데이터로 검증하기에서 종목과 날짜를 정한 뒤 백테스트 실행을 누릅니다. 이 입력은 정기 연구 대상을 바꾸지 않습니다.
정기 연구저장한 종목을 정기적으로 검증하기에서 대상 저장, 정기 연구 사용, 실행 간격과 검증 기간을 저장합니다.

정기 실행은 저장한 종목과 검증 기간, 기본 자금·비용 가정을 사용합니다. 수동 백테스트에서 바꾼 자금·비용과 시장 이벤트 입력은 이어받지 않습니다.

두 방식 모두 KIS 모의투자 일봉을 사용합니다. 정기 실행의 평가 기간은 서로 겹칠 수 있으므로 매번 완전히 새로운 표본이라고 볼 수 없습니다.

결과 숫자 읽기

총수익률초기 현금 대비 마지막 평가액 변화입니다. 높아도 미래 수익을 보장하지 않습니다.
최대 낙폭평가액 고점에서 이후 저점까지 가장 크게 줄어든 비율입니다. 작을수록 변동 손실이 제한됐다는 뜻입니다.
비용수수료, 매도세, 슬리피지 가정을 따로 표시합니다. 실제 비용과 다를 수 있습니다.
거래 수가정한 매수·매도 체결 횟수입니다. 횟수가 적으면 결과의 통계적 근거도 약할 수 있습니다.

가상 비교 예시

전략수익률최대 낙폭거래 수판정
기준-3%8%12비교 기준
후보-1%6%8합격 가능

위 값은 설명용 가상 숫자입니다. 후보가 기준보다 수익률이 높고 낙폭이 낮아 합격해도 두 전략 모두 손실일 수 있습니다.

확정 일봉 신호와 실시간 가격

먼저 앱 모의 전략으로 선택을 눌러 전략을 직접 고르고, 연결 켜기로 읽기 전용 시세를 연결합니다. 추천 표시는 자동 선택이나 자동 체결을 뜻하지 않습니다.

전략의 매수·매도 방향은 장이 끝난 확정 일봉으로 계산합니다. 실시간 KIS 체결가는 그 방향을 새 장중 전략으로 바꾸지 않습니다. 현재 가격이 제안의 가격 한도 안인지 확인하고, 승인 직전 시세가 신선한지 검증하는 데 사용합니다.

제안 내용을 확인한 뒤 모의 체결 승인 또는 거절을 누릅니다. 연결이 끊기거나 시세가 지연되거나 확정 일봉 근거가 바뀌면 승인을 처리하지 않습니다.

승인은 증권사 주문 승인이 아닙니다. 체결은 이 앱의 모의 원장에만 기록됩니다.

OpenAI 후보의 흐름

  1. API 키, 모델, 일일 예산이 없으면 OpenAI 검토는 꺼짐입니다. 결정론적 연구는 계속 동작합니다.
  2. 켜진 경우 AI는 제한된 이동평균·거래량 파라미터 후보만 제안합니다.
  3. 제안 생성 뒤 새 거래일 20개 이상을 모은 후속 구간에서 기준 전략과 비교합니다.
  4. 합격해도 자동으로 앱 모의 운영에 적용되지 않습니다. 사용자가 앱 모의 전략으로 선택해야 합니다.

AI는 합격 판정, 실행 코드 작성, 주문 실행을 맡지 않습니다.

자주 묻는 문제

제안이 없습니다

완료된 최근 일봉, 선택된 앱 모의 전략, 해당 종목의 진입·청산 조건이 모두 필요합니다. 조건이 유지 중이면 같은 신호를 반복해서 만들지 않습니다.

실시간 시세가 지연으로 표시됩니다

30초 동안 새 체결이 없으면 지연으로 표시합니다. 장 시작 전이나 휴장일에는 실제 체결 tick이 없을 수 있습니다.

거절하거나 만료한 제안이 다시 생기지 않습니다

같은 전략, 확정 일봉, 신호 입력은 다시 제안하지 않습니다. 새 확정 일봉이나 실제 신호 입력 변화가 있어야 새 제안이 가능합니다.

승인이 거부됩니다

만료, 가격 한도 이탈, 오래된 시세, 전략 변경, 현금·포지션 부족, 최신 일봉 근거 변경을 확인하세요.

현재 한계

  • 국내주식 일봉 추세·거래량과 KIS 체결가만 다룹니다.
  • 재무·업종 상대가치, 과거 뉴스·공시 backfill, 배당·총수익률, 호가잔량·부분 체결은 아직 포함하지 않습니다.
  • 공식 KRX 거래일 달력이 없어 모든 종목에 함께 빠진 일봉을 휴장일과 구분하지 못합니다.
  • 모든 체결은 앱 내부 모의 시뮬레이션입니다. 실제 증권사 주문 경로는 없습니다.
과거 결과와 합격 판정은 미래 성과를 보장하지 않습니다.
